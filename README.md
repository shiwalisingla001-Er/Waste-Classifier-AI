​AI Based Waste Classification System
​Submitted By: Shiwali Singla (AI&ML ) 

​ Project Aim:- 
​The primary goal of this project is to automate the process of waste segregation using Artificial Intelligence. Proper waste disposal is a major environmental challenge, and our system helps identify whether a piece of waste is Biodegradable or Non-Biodegradable simply by analyzing an image. By using this technology, we can improve recycling efficiency and reduce human effort in waste management.

​Technology Stack :- 

​We have used simple yet powerful tools to build this project:
​Python: The core programming language used for logic.
​Streamlit: Used to create a clean and interactive web-based user interface.
​TensorFlow/Keras: For implementing the image recognition model.
​MobileNetV2: A lightweight pre-trained model used for fast and accurate object detection.


​ How to Run the Project :- 

​Clone or download all the files from this repository.
​Open your Terminal or Command Prompt.
​Install the required libraries using the following command:
pip install -r requirements.txt
​Launch the application:
streamlit run app.py
​A browser window will open. Simply upload a photo of the waste, and the system will show the results.


​ Conclusion :- 

​Through this project, we explored how Machine Learning can solve real-world environmental issues. The model successfully identifies common items like fruits, plastic bottles, and paper with high accuracy. In the future, this system can be integrated with hardware like a Raspberry Pi to create a "Smart Dustbin" that automatically sorts waste at the source.
